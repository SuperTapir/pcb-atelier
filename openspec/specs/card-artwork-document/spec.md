## Requirements
### Requirement: 带版本的双面卡片工程
系统 MUST 将艺术卡保存为带 schema 版本的工程，并且必须包含物理板框、基础叠层、正面
与背面内容，以及可复现生产层编译所需的资产引用和参数。

#### Scenario: 创建基础卡片工程
- **WHEN** 用户创建一个标准卡片工程
- **THEN** 系统创建带正面、背面、毫米尺寸板框和默认基材/阻焊/表面处理的带版本工程

### Requirement: 打开已有 PCB Atelier 工程
桌面客户端 MUST 允许用户通过系统文件选择器打开 `.pcba` 工程。系统 MUST 在完整校验
项目包、schema、文档和内嵌资产后替换当前工作会话，并恢复正反面内容、生产映射和板体
参数。打开失败 MUST 保留当前工程不变，不得把嘉立创 EDA 工程误当成可双向编辑的
PCB Atelier 工程。

#### Scenario: 打开有效工程
- **WHEN** 用户选择一个包含图片、文字和生产映射的有效 `.pcba` 文件
- **THEN** 编辑器必须显示该工程的标题、板体、正反面对象和映射，并以空的撤销历史开始新会话

#### Scenario: 拒绝损坏工程
- **WHEN** 用户选择损坏、schema 不兼容或资产校验失败的 `.pcba` 文件
- **THEN** 系统必须显示打开失败原因，并完整保留此前正在编辑的工程

### Requirement: 工程首页与本地保存闭环
桌面客户端启动时 MUST 提供独立工程首页，至少包含新建工程和打开本地工程；文件生命周期
操作不得与主题选择、编辑工具和 EDA 导出挤在同一工具栏区域。进入编辑器后，左上工程菜单
MUST 提供新建、打开、保存和另存为；新工程首次保存 MUST 选择 `.pcba` 路径，已有路径的
工程执行保存 MUST 原子替换同一文件。

#### Scenario: 新建并首次保存
- **WHEN** 用户从工程首页新建标准卡片并执行保存
- **THEN** 系统必须显示系统保存面板、生成可重新打开的 `.pcba` 工程，并在标题区显示已保存状态

#### Scenario: 保存已有本地工程
- **WHEN** 用户打开本地 `.pcba`、修改内容后执行保存
- **THEN** 系统必须写回原路径，保留全部内嵌资产，并在保存失败时保留旧文件和当前编辑状态

### Requirement: 内容图层树
系统 MUST 支持图片层、文字层和组；每个内容层必须具有稳定 ID、名称、显隐、锁定、
是否参与生产导出、排序、父组关系和以物理单位表示的变换。显隐与是否参与生产导出
必须是独立状态。

#### Scenario: 保存分组后的内容
- **WHEN** 用户将图片层和文字层放入一个组并保存工程
- **THEN** 重新打开后层级、顺序、可见性、锁定状态、导出参与状态和物理变换必须保持不变

#### Scenario: 隐藏内容但保留生产输出
- **WHEN** 用户隐藏一个仍启用生产导出的内容层
- **THEN** 内容画布不得显示该层，但生产编译仍必须包含其已启用映射

### Requirement: 内容层与生产层分离
系统 MUST 将内容层与 PCB 生产层分开保存。生产映射必须明确目标面、目标层和组合语义，
且不得把画布库对象 JSON 作为生产层的真相来源。

#### Scenario: 一个内容映射到多个生产层
- **WHEN** 用户将一个图片层映射到顶铜和顶阻焊开窗
- **THEN** 工程必须保存两项明确映射，并能在后续编译中独立生成这两个生产层

### Requirement: 板体参数可编辑且不缩放内容
系统 MUST 将宽度、高度、圆角半径、板厚、阻焊颜色和表面处理保存为共享板体参数。
首版基材 MUST 固定为 FR-4。修改板框 MUST 默认保留既有对象的物理坐标和实际尺寸，
不得自动按比例缩放内容。

#### Scenario: 缩小板体后对象越界
- **WHEN** 用户缩小板体导致既有对象部分或全部位于新板框外
- **THEN** 系统必须保留该对象的坐标与尺寸、给出明确越界警告，并让生产裁切、双画板、3D 预览和导出使用新板框

### Requirement: 每面唯一基础铺铜
系统 MUST 默认限制每个卡面最多一个基础铺铜源对象。该约束 MUST 在领域命令中执行，
不能只依赖 UI 隐藏按钮。

#### Scenario: 重复创建基础铺铜
- **WHEN** 当前卡面已经存在基础铺铜且再次请求创建
- **THEN** 系统必须返回既有铺铜的稳定 ID，不得创建第二个同名或重叠铺铜

### Requirement: 统一物理坐标与背面语义
系统 MUST 以整数微米保存生产语义坐标；正面和背面都必须保存为板自身坐标，背面镜像
不得写入持久内容变换。编辑模式中的背面画板 MUST 默认使用正向设计视图，使文字、图片
和操作坐标保持正立；物理翻面观看方向只属于 3D 预览或显式生产检查。

#### Scenario: 在正向视图编辑背面
- **WHEN** 用户激活背面画板进行排版
- **THEN** 文字和图片必须正向显示，指针、拖动与检查器坐标必须直接对应板体物理坐标，工程数据和导出方向不得被改写
