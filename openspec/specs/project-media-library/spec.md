# project-media-library Specification

## Purpose
定义工程内嵌媒体资产的组织、去重、拖放、引用与可重建代理缓存，使素材能够脱离原始磁盘路径
跨设备保存和复用，同时明确资产、处理版本、画布实例与生产映射之间的生命周期边界。

## Requirements
### Requirement: 项目级嵌入媒体库
系统 MUST 在 `.pcba` 工程内保存项目使用的原始图片资产，并以内容哈希去重。资产字节
MUST 独立于画布放置实例和生产映射；移动、复制或删除实例不得改写原始资产。

#### Scenario: 重复导入同一图片
- **WHEN** 用户把字节完全相同的图片再次导入当前工程
- **THEN** 系统必须复用同一资产字节和哈希，但允许创建名称、处理版本和位置不同的实例

#### Scenario: 将工程交给另一台电脑
- **WHEN** 用户保存包含图片的工程并在不存在原始磁盘文件的电脑上打开
- **THEN** 所有素材、处理版本、画布实例、3D 预览和导出必须仍可完整使用

### Requirement: 素材组织与大屏并行 Dock
系统 MUST 提供带搜索、文件夹、缩略图/列表、尺寸、格式、透明通道和使用次数的项目素材
面板。桌面大屏默认 MUST 让素材面板与生产层树同时可见，并允许调整、折叠和持久化各自
尺寸；空间不足时可以收纳为临时抽屉，但不得要求大屏用户在素材和图层间反复切换。

#### Scenario: 从素材面板拖入活动生产层
- **WHEN** 用户把已有素材拖到正面画板，且正面阻焊开窗是当前工作层
- **THEN** 系统必须创建新的正面放置实例、建立合法阻焊开窗映射并保留素材面板和图层树状态

#### Scenario: 使用 P 打开素材
- **WHEN** 画布拥有快捷键焦点且用户按下 `P`
- **THEN** 系统必须展开并聚焦素材面板，允许选择已有素材或导入新素材，不得遮蔽或替换生产层树

### Requirement: 外部文件与项目素材使用明确的拖放语义
系统 MUST 根据拖放来源和落点区分“只导入资产”与“放置实例”。从操作系统拖入的受支持图片
落到画板时，系统 MUST 以落点所在卡面和该卡面当前活动生产层为目标，完成资产导入/去重、
默认处理版本、实例创建和合法生产映射，并把实例放在落点对应的物理位置。从操作系统拖到
媒体库时，系统 MUST 只导入/去重资产，不得创建画布实例、处理映射或改变活动卡面。从媒体库
拖到画板时，系统 MUST 复用已有资产并创建新的放置实例和目标生产映射，不得复制资产字节。

任何画板落点在提交前 MUST 校验文件类型、目标卡面和当前生产层是否允许图片；失败时必须
说明原因，且不得留下半完成实例或无效映射。成功的画板放置 MUST 作为一个可撤销事务，并
选中新实例；仅导入媒体库不应伪装成画布编辑。

#### Scenario: 外部图片直接拖到背面丝印
- **WHEN** 背面丝印是当前活动生产层，用户把操作系统中的图片拖到背面画板坐标
- **THEN** 系统必须导入或复用资产，在该物理坐标创建背面图片实例和丝印映射，并选中新实例

#### Scenario: 外部图片拖到媒体库
- **WHEN** 用户把操作系统中的图片拖到媒体库面板
- **THEN** 系统必须只增加或复用项目资产，正背面实例数、生产映射和活动卡面必须保持不变

#### Scenario: 媒体库素材拖到正面铜层
- **WHEN** 正面铜是当前活动生产层，用户把已有媒体库素材拖到正面画板
- **THEN** 系统必须复用该资产字节并创建新的正面实例和铜层映射，原有实例不得移动或被替换

#### Scenario: 拖到不接受图片的目标
- **WHEN** 用户把外部图片或媒体库素材拖到当前不允许图片内容的目标
- **THEN** 系统必须拒绝放置并说明目标约束，不得创建实例或无效生产映射

### Requirement: 素材替换、删除与引用关系
系统 MUST 区分“替换当前实例”“替换资产的全部引用”“删除实例”和“删除资产”。被引用
资产不得在无提示的情况下删除；全局替换必须保留每个实例的稳定 ID、变换、裁切和生产映射。

#### Scenario: 全局替换素材
- **WHEN** 一个 Logo 资产被三个实例使用且用户选择替换该资产的全部引用
- **THEN** 三个实例必须引用新资产内容并保留各自位置、尺寸、处理版本关联和生产层映射

#### Scenario: 删除最后一个实例
- **WHEN** 用户删除某资产的最后一个画布实例
- **THEN** 资产必须保留在项目媒体库并标记为未使用，直到用户显式清理未使用素材

### Requirement: 代理缓存不是工程真相
系统 MAY 缓存缩略图和低分辨率处理代理以提高交互速度，但缓存 MUST 可由原始资产、处理
配方和栅格器版本完全重建。保存、CLI 和正式导出不得依赖无法重建的 UI 缓存。

#### Scenario: 清除所有媒体缓存
- **WHEN** 工程代理缓存被删除后重新打开
- **THEN** 系统必须从项目资产和处理配方重建相同语义的编辑代理、3D 纹理和正式生产输出
