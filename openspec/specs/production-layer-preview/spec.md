## Requirements
### Requirement: 显式生产层栈
系统 MUST 编译并显示顶铜、顶阻焊开窗、顶丝印、底铜、底阻焊开窗、底丝印、板框和钻孔。
系统必须将基材、阻焊颜色与表面处理作为基础叠层信息，而不是内容图层。

#### Scenario: 查看正面生产层栈
- **WHEN** 用户在编辑模式选择正面生产层工作节点
- **THEN** 系统必须显示基材上的顶面生产层，并允许独立显示或隐藏每个生产层

### Requirement: 生产层映射与调整
系统 MUST 允许用户通过生产层对象树添加、移除和检查目标生产层关联，并允许在编辑模式左侧树中进行
显隐、隔离和基础叠层选择；生产层调整不得隐式改变其他层的极性。编译后的生产层 MUST
作为可追溯的派生结果呈现，不得作为普通内容对象直接编辑。

#### Scenario: 将文字关联为顶丝印
- **WHEN** 用户将铜层文字高级关联到顶丝印
- **THEN** 两个生产层下必须显示同一源对象的关联项，2D 预览按各自生产层显示结果

#### Scenario: 隔离生产层不改变导出
- **WHEN** 用户临时隔离顶丝印以检查细节
- **THEN** 系统只能改变当前生产预览的显隐，任何内容层的导出参与状态和映射均不得改变

#### Scenario: 从生产图形追溯内容
- **WHEN** 用户检查生产层中的一个已编译图形
- **THEN** 系统必须允许定位其来源内容层和映射，不得要求用户编辑派生纹理

### Requirement: 生产层是预览真相
2D 生产预览 MUST 消费已编译生产层，而不是直接渲染内容画布；预览与导出必须共享物理
尺寸、原点、固定生产网格、板框裁切、层极性和正反面语义。图片、文字和内容变换
MUST 在统一编译阶段解析为最终生产 mask；预览和导出器不得各自重新栅格化内容。

#### Scenario: 检查阻焊开窗极性
- **WHEN** 用户预览一个映射到顶阻焊开窗的非对称图案
- **THEN** 预览必须将图案表示为不盖阻焊的开窗，并与编译生产层的几何完全一致

#### Scenario: 预览与导出消费相同生产 mask
- **WHEN** 用户编译包含图片和文字的卡片并随后预览和导出
- **THEN** 两条路径必须消费同一个带输入哈希与栅格器版本的最终生产 mask，且不得再次读取源图片或系统字体

### Requirement: 背面生产预览
系统 MUST 让编辑态背面生产层纹理与正向设计画板对齐，不得镜像可编辑对象。物理翻面
观看方向 MUST 仅用于 3D 成板预览或用户显式进入的生产检查，同时保持底层生产几何处于
板坐标中。

#### Scenario: 检查非对称背面标记
- **WHEN** 用户在背面编辑态查看包含非对称 `B` 标记的生产层
- **THEN** 标记必须与正向背面内容对齐且保持正立，领域坐标和导出坐标不得因此被修改

### Requirement: 整体 3D 成板预览
系统 MUST 在顶层预览模式中提供只读的整体 3D 成板视图。板体比例、板框、孔、正背面
生产图形与叠层颜色 MUST 消费 `ResolvedFabricationBoard` 和 `StackupPreset`，不得
从内容画布另行近似生产几何。用户 MUST 能拖动旋转、缩放和平移相机。

#### Scenario: 旋转查看正反面
- **WHEN** 用户拖动 3D 板体从正面旋转到背面
- **THEN** 系统必须连续显示符合物理观看方向的正背面材质，且不得修改领域坐标或导出方向

#### Scenario: 预览中尝试编辑
- **WHEN** 用户在 3D 预览中点击或拖动板上图形
- **THEN** 系统只能改变相机或查看状态，不得修改内容层、生产映射或命令历史

### Requirement: 预览响应与版本一致性
系统 MUST 按工程 revision 和处理配方指纹缓存并复用交互结果，使对象级编辑代理、显式
2D 生产检查与 3D 成板预览来自同一版本化处理流水线。Tauri MUST 在后台任务执行图片
处理、首次生产板编译和纹理编码，不得同步阻塞桌面 UI。跨运行时边界的纹理 MUST 使用
紧凑图片编码传输，不得以 JSON 数字数组传输完整 RGBA 缓冲区。对象交互代理、3D 预览
和正式导出的栅格间距 MUST 明确分离，但物理边界、连通关系、极性、裁切和正反方向 MUST
保持一致。

#### Scenario: 编辑后切换 3D 预览
- **WHEN** 用户插入文字、图片或基础铺铜后切换到预览
- **THEN** 编辑操作必须立即反馈，3D 必须显示最新 revision 和配方指纹编译出的对象，且不得被较旧结果覆盖

#### Scenario: 普通编辑不重复叠加生产纹理
- **WHEN** 用户在编辑模式插入或查看已映射的图片和文字，且尚未显式开启生产检查
- **THEN** 画布必须只显示一个可编辑生产近似对象，编译后的完整生产纹理不得默认叠加造成重影

#### Scenario: 移动对象不重建图片处理结果
- **WHEN** 用户连续拖动、缩放或旋转处理后的图片
- **THEN** 编辑器必须变换已有对象代理并保持交互流畅，不得在每个指针事件重新解码原图或编译生产板

#### Scenario: 修改图片处理配方
- **WHEN** 用户停止调整阈值、平滑或去斑参数
- **THEN** 系统必须在后台生成新的对象代理和配方指纹，并丢弃晚于新 revision 返回的陈旧结果

#### Scenario: 复用同一 revision 的生产板
- **WHEN** 显式 2D 检查与 3D 成板预览连续请求同一工程 revision 和处理配方
- **THEN** WorkspaceService 必须只解析一次生产板，并让两个响应携带相同的生产输入与输出哈希

#### Scenario: 修改阻焊颜色
- **WHEN** 用户将板体阻焊颜色从哑黑改为白色
- **THEN** 编辑工艺近似必须立即更新，正反面最终成板纹理也必须使用白色阻焊效果，即使六层生产 mask 的几何哈希未变化

### Requirement: 编辑近似与正式生产几何一致
系统 MUST 使用非对称图片、文字、孤岛、细线和开窗黄金样例比较对象级编辑代理、3D 成板
和正式生产 mask。显示色彩和采样精度 MAY 不同，但结构性边界、连通关系、组合极性、
生产层归属和正背方向不得不同。

#### Scenario: 黄金图片跨精度验证
- **WHEN** 自动化以交互、3D 和正式导出三种精度处理同一图片配方
- **THEN** 测试必须验证配方指纹一致、轮廓误差不超过约定物理容差，且岛屿数量和孔洞拓扑相同

#### Scenario: 放大编辑图片生产代理
- **WHEN** 用户在编辑画布将处理后图片从适配视图连续放大到 400%
- **THEN** 编辑器必须按离散精度档位提高对象代理密度，使最高缩放下一个代理像素不超过
  一个 CSS 像素，同时复用同档缓存且不得在每个滚轮事件重新编译
