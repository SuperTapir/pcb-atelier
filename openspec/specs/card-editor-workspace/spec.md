## Requirements
### Requirement: 双画板与活动卡面
系统 MUST 提供以毫米为尺度的正面和背面两块独立 2D 画板，并在编辑模式下默认同时
显示。宽空间 MUST 并排显示，空间不足时 MUST 自适应为上下排列。正面和背面 MUST
是同一物理卡片的两个固定第一等视图，不得表现为用户可任意增删的普通页面。

#### Scenario: 点击背面成为活动卡面
- **WHEN** 用户在同时查看布局中点击背面画板
- **THEN** 背面必须成为活动卡面，内容树、检查器和后续插入必须跟随背面，正面内容不得改变

#### Scenario: 两面保留独立状态
- **WHEN** 用户在正面选择对象并缩放视口，再激活背面选择另一对象并平移视口
- **THEN** 两块画板必须分别保留自己的选择路径和视口状态

#### Scenario: 聚焦后恢复同时查看
- **WHEN** 用户从同时查看切换为聚焦当前面，再恢复同时查看
- **THEN** 另一面的内容、选择和视口状态必须完整保留

#### Scenario: 背面以正向设计视图编辑
- **WHEN** 用户激活背面画板并编辑文字、图片或图形
- **THEN** 背面内容必须像正面一样正立显示，拖动、缩放、旋转、文字输入和指针坐标不得因物理翻面而镜像或反转

#### Scenario: 手动选择正反画板排列方向
- **WHEN** 用户在同时查看中选择左右排列或上下排列
- **THEN** 系统必须按指定方向显示两块画板，在空间不足时允许工作区滚动，且不得丢失活动卡面、选择或视口状态

### Requirement: 在活动生产层插入图片和文字
系统 MUST 允许用户在活动生产层插入合法的图片、文字和图形。系统内部必须创建稳定
源对象并自动建立到当前生产层的映射，但一级 UI 不得暴露独立“内容层”。

#### Scenario: 插入图片和文字
- **WHEN** 用户在正面丝印层插入一张图片和一段文字
- **THEN** 系统必须把两个对象显示在正面丝印层下，并在内部创建两个稳定源对象和合法映射

#### Scenario: 插入图片后立即排版
- **WHEN** 用户通过文件、拖放或粘贴插入一张图片
- **THEN** 系统必须将图片等比适配并居中于活动卡面、立即选中，且不得改变另一面的选择

#### Scenario: 点击画板空白取消选择
- **WHEN** 用户使用选择工具点击当前画板的空白区域
- **THEN** 系统必须清空当前面的对象选择并移除选择框和变换控制点，不得删除或移动对象

#### Scenario: 替换图片资产
- **WHEN** 用户替换一个既有图片层的源资产
- **THEN** 系统必须保留该层的稳定 ID、变换、层级、锁定状态和生产映射

#### Scenario: 创建并编辑文字
- **WHEN** 用户点击建立点文字或拖动建立定宽文字，并双击或按 Enter 编辑
- **THEN** 系统必须使用原生文字输入完成编辑，并允许用 Escape 退出而不改变卡面视图

### Requirement: 基础对象编辑
系统 MUST 支持对未锁定图片和文字的单选/多选、拖动、缩放、旋转、镜像、排列顺序和
分组操作，并必须将最终操作写入领域命令历史。

#### Scenario: 拖动并缩放图片
- **WHEN** 用户拖动并缩放一个未锁定图片层后确认操作
- **THEN** 系统必须以毫米更新该层变换，并允许通过撤销恢复原变换

### Requirement: 生产层对象树
系统 MUST 以“板体 → 正面/背面 → 铜层、阻焊开窗、丝印层”作为左侧固定信息架构。
图片、文字、图形、组合和铺铜 MUST 直接显示在所属生产层下，不得提供独立“内容”
入口。系统 MUST 在画布和生产层对象树中一致地表现对象的锁定、显隐、排序和组关系。锁定对象不得响应
画布变换或检查器变换命令。锁定对象在画布中 MUST 不阻挡其下方可编辑对象的命中，
但 MUST 保持可从图层树选择、检查和解锁。图片、文字、图形、组合和铺铜等对象
MUST 允许用户重命名，且重命名必须进入撤销/重做历史；铜层、阻焊开窗和丝印层的
标准生产语义名称不得被对象重命名功能修改。
生产层的展开/收起状态 MUST 与当前编辑焦点独立。铜层、阻焊开窗和丝印层 MUST 允许
同时展开以比较对象；任一时刻仍只有一个生产层作为插入和生产操作的焦点。
对象 MUST 支持通过 Pointer Events 在同一父级排序、拖入组合、拖出组合，以及在同面
铜层、阻焊开窗和丝印层之间迁移。跨生产层拖拽 MUST 原子更新树层级、顺序和生产归属；
拖动组合时必须连同全部后代迁移。生产层标题本身作为移动到该生产层根部的投放目标，
拖动时不得插入导致列表跳动的临时占位行。合法目标 MUST 提供明确高亮；非法目标
MUST 在松手前显示禁止状态和 `not-allowed` 指针，且不得修改工程。右键对象行与行尾
`…` MUST 打开同一组上下文操作；不得以“上移/下移”按钮代替直接拖拽。
正反面的铜层、阻焊开窗和丝印层 MUST 默认显示；用户可临时隐藏或隔离它们，但该
检查状态不得改变生产映射或导出参与状态。

#### Scenario: 锁定图片层
- **WHEN** 用户锁定一个图片层并尝试在画布中拖动它
- **THEN** 系统不得改变该层变换，并必须允许用户继续选择其他未锁定层

#### Scenario: 在生产层树中重命名对象
- **WHEN** 用户双击生产层下未锁定对象的名称，或选中后按 Return/F2，输入新名称并确认
- **THEN** 系统必须保留对象稳定 ID、变换和生产映射，只更新显示名称，并允许通过撤销恢复旧名称

#### Scenario: 同时展开多个生产层
- **WHEN** 用户展开正面铜层、阻焊开窗和丝印层，并将阻焊开窗设为编辑焦点
- **THEN** 左侧必须同时显示三个生产层的对象，后续插入仍只进入获得焦点的阻焊开窗层

#### Scenario: 右键并拖拽对象
- **WHEN** 用户右键一个对象后查看操作，再把它拖到同级、组合内部或同面的另一生产层
- **THEN** 右键菜单必须与 `…` 菜单一致，拖拽必须原子更新对象顺序、父级和生产归属并进入撤销历史

#### Scenario: 非法跨层拖拽
- **WHEN** 用户尝试把基础铺铜拖入丝印层，或把组合拖入自己的后代
- **THEN** 目标必须在松手前显示禁止反馈，系统不得修改树结构、生产归属或撤销历史

#### Scenario: 左树多选
- **WHEN** 用户在生产层对象树中普通点击、按 Cmd/Ctrl 点击或按 Shift 点击对象
- **THEN** 系统必须分别执行单选、逐项增减选择和从选择锚点开始的连续范围选择，且必须直接选择所点击的组内对象而不是替换为父组合

### Requirement: 可预测的选择与精确摆放
系统 MUST 默认先选择组或父对象，并提供下钻选择、修饰键深选和重叠对象候选选择。
系统 MUST 提供毫米精确值、键盘微调，以及对网格、板边、对象边和中心的可见吸附。

#### Scenario: 选择组内重叠对象
- **WHEN** 用户先选中一个组，再下钻到指针下方的重叠子对象
- **THEN** 系统必须保持选择路径可理解，并允许从候选对象中明确选择目标

#### Scenario: 临时绕过吸附
- **WHEN** 用户拖动对象时使用绕过吸附的修饰键
- **THEN** 系统必须保持连续移动，并在操作完成后仍以物理单位提交最终变换

### Requirement: 工具、活动卡面、布局与模式正交
系统 MUST 将选择/文字/图片工具、活动卡面、同时查看/聚焦当前面布局和编辑/预览模式
保存为独立 UI 状态；切换其中一个不得隐式重置另外几个。编辑模式负责所有修改，
预览模式 MUST 只读并拥有独立的 3D 相机状态。

#### Scenario: 从编辑切换到预览再返回
- **WHEN** 用户在背面使用选择工具并切换到 3D 预览后返回编辑
- **THEN** 当前工具、活动背面、两面选择和两面视口必须保持不变

### Requirement: 有规则的生产层编辑容器
系统 MUST 让铜层、阻焊开窗和丝印成为有规则的编辑容器。铜层允许图片、文字、图形、
基础铺铜和挖空；丝印层允许图片、文字和普通图形但禁止铺铜；阻焊开窗允许图片、
文字轮廓和图形，并必须明确提供“添加开窗/减少开窗”。非法内容 MUST 在插入入口阻止。

#### Scenario: 在丝印层工作时插入文字
- **WHEN** 用户选择当前面的丝印工作节点后插入文字
- **THEN** 左侧必须将文字直接显示在该丝印层下，内部创建源对象并自动增加合法映射

#### Scenario: 从生产层子项定位源内容
- **WHEN** 用户选择生产工作节点下的一个来源子项
- **THEN** 系统必须定位同一稳定 ID 的源内容及映射，不得创建可独立变换的副本

#### Scenario: 编辑阻焊开窗
- **WHEN** 用户在阻焊开窗工作节点对图案选择添加或减少
- **THEN** 系统必须以显式 Add/Subtract 映射修改开窗 mask，并以“开窗”语义呈现结果

#### Scenario: 创建基础铺铜
- **WHEN** 用户在当前面的铜层工作节点创建铺铜并设置板边间距
- **THEN** 系统必须创建可撤销的板内铺铜源对象、只映射到该铜层，并允许显式对象挖空

#### Scenario: 在丝印层尝试铺铜
- **WHEN** 用户选择丝印层
- **THEN** “添加基础铺铜”入口必须不可用，系统也必须拒绝通过命令绕过该限制

#### Scenario: 再次添加基础铺铜
- **WHEN** 当前面已有基础铺铜且用户再次点击添加
- **THEN** 系统必须选中既有铺铜，不得创建重复对象

### Requirement: 生产映射作为内部实现
系统 MUST 保留源对象与生产映射以支持编译和历史兼容，但日常编辑界面不得暴露“关联”
术语、关联徽标或多选框矩阵。默认情况下，一个对象只归属于一个生产层；用户把对象
拖到同面的另一生产层时，系统 MUST 移动其生产归属而不是创建第二份关联。未来若提供
一源多层能力，必须作为有明确用途和结果预览的高级生产操作另行设计。

#### Scenario: 从丝印移动到铜层
- **WHEN** 用户把丝印层中的普通对象拖到同面铜层标题
- **THEN** 对象必须从丝印层树中消失并出现在铜层根部，稳定对象 ID 和物理变换保持不变，界面不得显示“关联”概念

### Requirement: 板体根节点与检查器
系统 MUST 提供不属于正面或背面的共享“板体”根节点。选中后，检查器 MUST 允许编辑
宽度、高度、圆角、板厚、阻焊颜色与表面处理；FR-4 MUST 固定且不在主要界面显示材料选择。

#### Scenario: 编辑板体尺寸
- **WHEN** 用户修改板体宽高
- **THEN** 正背画板、生产裁切、3D 预览和 EDA 导出必须同步使用新尺寸，既有对象不得自动缩放，越界对象必须被警告

### Requirement: Web 与 Tauri 能力契约一致
Web 与 Tauri MUST 调用同一版本的 Workspace 能力契约和 Rust 领域服务。Web MUST 支持
图片插入、分组、解组及由当前工程真实编译生成的 3D 预览；不得用硬编码测试纹理或
仅在 TypeScript fixture 中模拟领域状态。

#### Scenario: Web 编辑后查看 3D
- **WHEN** 用户在 Web 插入图片、分组对象并进入预览
- **THEN** Web 必须从当前工程编译 `ResolvedFabricationBoard`，3D 纹理必须反映刚才的编辑且与 Tauri 对同一工程的哈希一致

#### Scenario: Web 与 Tauri 使用相同紧凑预览契约
- **WHEN** Web bridge 或 Tauri 请求生产层检查及 3D 成板纹理
- **THEN** 两端必须接收相同字段和 PNG 纹理契约，不得由任一端回退为硬编码纹理或完整 RGBA JSON 数组

### Requirement: 撤销和重做
系统 MUST 对本轮支持的内容插入、删除、变换、排序、分组、锁定、显隐和生产映射操作
提供撤销与重做。

#### Scenario: 重做已撤销的文本插入
- **WHEN** 用户插入文字、撤销，再执行重做
- **THEN** 系统必须恢复同一稳定 ID 的文字层及其映射状态

### Requirement: 大屏优先的可调整工作区 Dock
编辑器 MUST 以桌面大屏为主要工作环境，让生产层树与项目素材库默认并行可见，并允许用户
调整、折叠和持久化 Dock 尺寸。中央双画板和右侧检查器 MUST 保留可工作的最小尺寸；小屏
降级不得改变领域状态。

#### Scenario: 在 1920 宽度工作
- **WHEN** 用户以大屏打开编辑器
- **THEN** 图层树、素材库、双画板和检查器必须同时可用，用户可直接把素材拖到画板而无需切换左侧标签

#### Scenario: 恢复 Dock 布局
- **WHEN** 用户调整素材与图层面板比例、关闭并重新打开客户端
- **THEN** 系统必须恢复面板尺寸和折叠状态，同时保持工程内容与项目文件解耦

### Requirement: 三状态画板视图与全局设置本地持久化
系统 MUST 使用一个三状态选择器统一表达“左右”“上下”“聚焦当前面”，不得再把画板排列
和卡面查看拆成两组并列控件，也不得提供“自动”模式。无已保存偏好时 MUST 默认使用“左右”。
“聚焦当前面”只显示当前活动卡面，切换活动面时必须随之切换显示，但不得丢失另一面的选择、
视口或编辑状态。

顶部三状态选择器和设置页 MUST 读写同一个设备本地 `canvasView` 偏好，切换工程、关闭并
重新打开客户端后仍须恢复。设置页 MUST 以一个“默认画板视图”设置承载这三个值，并继续
承载主题、滚轮缩放阻尼、启动窗口方式及后续设备级全局偏好。启动窗口方式 MUST 提供
“窗口化全屏”“系统全屏”“普通窗口”三个稳定值并默认使用“窗口化全屏”；窗口化全屏
表示最大化普通窗口，保留系统窗口边界且不进入独占全屏空间。滚轮缩放阻尼 MUST 提供“高”“中”“低”
三档并默认使用“中”；高阻尼 MUST 比中阻尼缩放更慢，低阻尼 MUST 比中阻尼缩放更快。
画板视图、主题、启动窗口方式与缩放阻尼 MUST 与工程内容解耦，不得写入 `.pcba`、触发工程脏状态或进入
撤销/重做历史。

#### Scenario: 首次打开双画板
- **WHEN** 客户端没有已保存的 `canvasView` 偏好且用户打开任意双面工程
- **THEN** 正面和背面画板必须左右排列并同时可见，顶部选择器和设置页均必须显示“左右”

#### Scenario: 持久化上下排列
- **WHEN** 用户选择“上下”、关闭客户端并重新打开另一个工程
- **THEN** 双画板必须恢复为上下排列，偏好不得随工程切换而变化，也不得改写任一工程文件

#### Scenario: 持久化聚焦当前面
- **WHEN** 用户选择“聚焦当前面”、关闭客户端并重新打开工程
- **THEN** 系统必须只显示当前活动卡面并恢复“聚焦当前面”偏好，切换活动面后必须显示新活动面且保留另一面的视口和编辑状态

#### Scenario: 切换画板排列后自动适配
- **WHEN** 用户在“左右”“上下”或“聚焦当前面”之间切换
- **THEN** 系统必须在新布局稳定后按每块画板的实际可用区域重新适配缩放与居中位置，不得沿用旧布局下过小或被裁切的视口

#### Scenario: 在设置页修改主题
- **WHEN** 用户在设置页修改主题并重新启动客户端
- **THEN** 系统必须恢复该设备上的主题，且打开或保存工程不得序列化该主题偏好

#### Scenario: 持久化高阻尼
- **WHEN** 用户在设置页把滚轮缩放阻尼设为“高”、重启客户端并打开另一个工程
- **THEN** 设置页和画布必须继续使用高阻尼，且两个工程文件均不得记录该偏好或产生脏状态

#### Scenario: 默认以窗口化全屏启动
- **WHEN** 桌面客户端没有已保存的启动窗口偏好并首次打开
- **THEN** 主窗口必须以最大化普通窗口启动，默认逻辑尺寸不得小于 `1440 × 900`，且设置页必须显示“窗口化全屏”

#### Scenario: 持久化系统全屏
- **WHEN** 用户在设置页选择“系统全屏”并重新启动桌面客户端
- **THEN** 客户端必须进入系统全屏；改回“普通窗口”后下次启动不得继续最大化或进入系统全屏

### Requirement: 顶部模式控件保持稳定几何位置
画板三状态选择器 MUST 以整个应用窗口的几何中心为基准水平居中，不得因左侧 Dock、右侧
检查器宽度或其展开状态而偏移。编辑/预览切换 MUST 固定在顶部右侧的稳定位置并保持相同
占位尺寸，切换模式时不得导致自身、画板选择器或相邻控件跳动。撤销和重做 MUST NOT 常驻
顶部栏，但对应快捷键与菜单命令 MUST 保留并继续使用统一命令注册表。

#### Scenario: 左右面板宽度不同
- **WHEN** 用户调整左侧 Dock 或右侧检查器宽度
- **THEN** 三状态画板选择器的中心必须仍与应用窗口水平中心重合，不得仅相对剩余画布区域居中

#### Scenario: 切换编辑与预览
- **WHEN** 用户连续切换“编辑”和“预览”
- **THEN** 切换控件必须保持在顶部右侧同一几何位置且宽度稳定，三状态画板选择器不得位移

#### Scenario: 顶栏不显示撤销重做
- **WHEN** 用户进入编辑工作区
- **THEN** 顶部栏不得显示撤销或重做按钮，但 `Cmd/Ctrl+Z`、`Cmd/Ctrl+Shift+Z` 及菜单入口必须继续可用并反映相同历史状态

### Requirement: 左键内容与右键视口手势互斥
左键 MUST 只用于激活卡面、选择、框选和移动设计对象；右键拖动 MUST 平移开始手势的
画板且不改变选择。右键原地释放 MUST 打开指针所在对象或空白区域的上下文菜单。系统
MUST 使用移动阈值区分右键点击与拖动，并阻止浏览器原生菜单。

#### Scenario: 从图片上右键拖动画布
- **WHEN** 用户在已选图片内部按下右键并移动超过手势阈值
- **THEN** 只允许当前画板视口平移，图片选择和物理变换不得改变，也不得打开上下文菜单

#### Scenario: 右键点击图片
- **WHEN** 用户在图片上按下并原地释放右键
- **THEN** 系统必须选择或保持该图片并打开对象菜单，不得移动视口

#### Scenario: 左键拖动画板空白
- **WHEN** 选择工具下用户在空白处左键拖动
- **THEN** 系统必须显示框选区域并选择命中的未锁定对象，不得平移画布

### Requirement: 连续且指针锚定的滚轮缩放
滚轮或触控板缩放 MUST 使用输入事件的连续 delta 计算比例变化，不得把每次事件量化为固定
缩放台阶。缩放前后指针下的板上物理位置 MUST 保持不变。设备级“高/中/低”阻尼只能调整
delta 到缩放倍率的响应系数，不得改变缩放方向、锚点、最小/最大倍率或正背面独立视口语义。

#### Scenario: 不同 delta 产生不同缩放量
- **WHEN** 用户在同一阻尼档位、同一指针位置依次输入小幅和大幅同方向滚轮 delta
- **THEN** 两次缩放必须保持同一板上锚点，且大幅 delta 产生的倍率变化必须大于小幅 delta

#### Scenario: 高阻尼缩放更慢
- **WHEN** 用户分别在高、中、低阻尼下输入相同 delta
- **THEN** 三次缩放方向和指针锚点必须一致，倍率变化绝对值必须满足高阻尼小于中阻尼、中阻尼小于低阻尼

### Requirement: 画布 HUD 只保留方位与缩放
每块可见画板的 HUD MUST 只显示“正面”或“背面”以及当前缩放百分比。系统 MUST 移除板内
`FRONT`/`BACK` 大字、常驻手势教学提示、指针坐标读数、画板尺寸和当前生产层 badge。
对象坐标、物理尺寸、生产层和其他精确属性 MUST 由检查器按选择上下文提供，不得在画布上
重复常驻。

#### Scenario: 查看未选中的双画板
- **WHEN** 用户以左右或上下视图打开正背画板且没有选择对象
- **THEN** 每块画板只能看到对应“正面”或“背面”和缩放百分比，不得出现板内英文方位大字、手势提示、坐标、尺寸或生产层 badge

#### Scenario: 选择对象查看精确属性
- **WHEN** 用户选择一个已映射对象
- **THEN** 对象坐标、物理尺寸和生产层必须由检查器显示，画布 HUD 仍只能保留方位与缩放百分比

### Requirement: 统一编辑命令与快捷键作用域
系统 MUST 建立独立于 UI 入口的编辑命令注册表。快捷键、对象右键菜单、生产层菜单和
检查器 MUST 调用同一命令并获得相同的锁定校验、撤销记录和状态反馈。画布快捷键在文本
输入、数值输入、内容可编辑元素或模态窗口拥有焦点时 MUST 暂停。

#### Scenario: Delete 删除选择
- **WHEN** 画布拥有焦点且用户选中未锁定对象后按 `Delete` 或 `Backspace`
- **THEN** 系统必须删除源对象及其全部映射、保留项目素材并允许撤销

#### Scenario: P 插入图片
- **WHEN** 画布拥有焦点且用户按 `P`
- **THEN** 系统必须激活图片工具并聚焦项目素材库，后续插入目标跟随活动卡面和生产层

#### Scenario: 在文字输入中按快捷键
- **WHEN** 用户正在编辑文字并输入 `V`、`T`、`P` 或按 `Backspace`
- **THEN** 按键必须只作用于文字输入，不得切换工具或删除画布对象

### Requirement: 图层面板分组操作按选择上下文出现
图层面板 MUST NOT 在底部常驻大号分组或解组按钮。仅当多选内容可以组合，或当前选择包含
可解组的组合时，系统 MUST 显示紧凑上下文操作条，并只展示当前可执行的分组或解组动作。
没有可用动作时，操作条 MUST 完全隐藏且不得保留布局占位。操作条、右键菜单和快捷键 MUST
复用统一命令注册表及其启用条件、撤销和状态反馈。

#### Scenario: 多选可组合对象
- **WHEN** 用户在图层树或画布中选择两个可组合对象
- **THEN** 图层面板必须显示紧凑的“分组”操作，执行结果必须与右键菜单或快捷键分组一致

#### Scenario: 选中一个组合
- **WHEN** 用户只选中一个可解组的组合
- **THEN** 图层面板必须只显示紧凑的“解组”操作，不得同时显示不可执行的“分组”

#### Scenario: 没有分组上下文
- **WHEN** 用户没有选择、只选择普通单个对象或选择状态不允许分组与解组
- **THEN** 图层面板底部不得显示操作条或保留空白高度

### Requirement: 对象菜单与删除语义
对象上下文菜单 MUST 至少提供编辑、重命名、复制、创建副本、锁定、显隐、组合/解组、
关联到其他生产层、移出当前生产层和删除对象。删除对象 MUST 删除源对象和全部映射；
移出当前生产层 MUST 只删除当前映射，两者不得使用含糊的同一标签。

#### Scenario: 创建图片副本
- **WHEN** 用户通过 `Cmd/Ctrl+D` 或菜单创建图片副本
- **THEN** 系统必须创建新实例 ID、复用同一媒体资产、复制处理版本与生产映射，并以可见物理偏移放置副本

#### Scenario: 移出一个关联生产层
- **WHEN** Logo 同时关联铜和阻焊开窗且用户从阻焊开窗菜单选择“移出当前生产层”
- **THEN** 系统必须只移除阻焊开窗映射，Logo 实例和铜层映射必须保留

### Requirement: 编辑画布显示单一生产近似对象
图片、文字和图形在编辑画布中 MUST 以所属生产层的处理后轮廓和工艺近似色显示，而不是
默认显示会被生产处理改变的原始外观。生产近似 MUST 作为同一可编辑节点的外观，不得在
节点下方叠加完整编译纹理形成第二份内容。

#### Scenario: 图片确认导入后排版
- **WHEN** 用户把彩色图片处理为丝印黑白轮廓并确认插入
- **THEN** 画布必须显示该丝印轮廓和一个选择框，切换 3D 时不得出现原图到另一图案的结构突变

#### Scenario: 同一对象显示多个生产材料
- **WHEN** 一个对象关联多个当前可见生产层
- **THEN** 系统可以合成其材料近似，但只能保留一个命中目标、一个选择框和一套变换
