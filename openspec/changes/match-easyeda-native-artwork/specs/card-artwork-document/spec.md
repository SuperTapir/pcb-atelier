## MODIFIED Requirements

### Requirement: 打开已有 PCB Atelier 工程
桌面客户端 MUST 允许用户通过系统文件选择器打开 `.pcba` 工程。打开命令 MUST 在当前
工程菜单关闭后调用系统文件选择器，并将选择、取消和错误作为三个可观察结果处理。系统
MUST 在完整校验项目包、schema、文档和内嵌资产后替换当前工作会话，并恢复正反面内容、
生产映射和板体参数。打开失败 MUST 显示可定位的原因并保留当前工程不变，不得把嘉立创
EDA 工程误当成可双向编辑的 PCB Atelier 工程。

#### Scenario: 打开有效工程
- **WHEN** 用户执行“打开工程”并选择一个包含图片、文字和生产映射的有效 `.pcba` 文件
- **THEN** 系统文件选择器必须关闭，编辑器必须显示该工程的标题、板体、正反面对象和映射，并以空的撤销历史开始新会话

#### Scenario: 取消打开工程
- **WHEN** 用户执行“打开工程”后取消系统文件选择器
- **THEN** 系统不得替换当前工程、改变保存路径或显示伪失败状态，工程菜单必须保持可再次操作

#### Scenario: 拒绝损坏工程
- **WHEN** 用户选择损坏、schema 不兼容或资产校验失败的 `.pcba` 文件
- **THEN** 系统必须显示打开失败原因，并完整保留此前正在编辑的工程

### Requirement: 工程首页与本地保存闭环
桌面客户端启动时 MUST 提供独立工程首页，至少包含新建工程和打开本地工程；文件生命周期
操作不得与主题选择、编辑工具和 EDA 导出挤在同一工具栏区域。进入编辑器后，左上工程菜单
MUST 提供新建、打开、保存和另存为，并且每个命令都 MUST 在当前菜单关闭后进入系统文件
对话框或领域保存操作，不得无反馈地结束。新工程首次保存 MUST 选择 `.pcba` 路径，已有
路径的工程执行保存 MUST 原子替换同一文件；另存为 MUST 总是选择新路径。成功保存后标题、
路径和脏状态 MUST 同步更新，取消或失败 MUST 保留当前工作区及上一次有效文件。

#### Scenario: 新建并首次保存
- **WHEN** 用户从工程首页新建标准卡片并执行保存
- **THEN** 系统必须显示系统保存面板、生成可重新打开的 `.pcba` 工程，并在标题区显示已保存状态

#### Scenario: 保存已有本地工程
- **WHEN** 用户打开本地 `.pcba`、修改内容后执行保存
- **THEN** 系统必须写回原路径，保留全部内嵌资产，并在保存失败时保留旧文件和当前编辑状态

#### Scenario: 另存为后重新打开
- **WHEN** 用户对包含正反面图片、文字和生产映射的工程执行“另存为”并选择新路径
- **THEN** 系统必须生成可重新打开的 `.pcba` 文件、把当前保存路径切换到新文件，并在重新打开后恢复相同内容、映射、字符和物理变换

#### Scenario: 取消首次保存或另存为
- **WHEN** 用户在系统保存面板中取消首次保存或另存为
- **THEN** 系统不得创建文件、改变当前保存路径或清除脏状态，工程菜单必须保持可再次操作
