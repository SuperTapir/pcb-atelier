## ADDED Requirements

### Requirement: 可无损内容使用 EasyEDA 原生图元
EasyEDA handoff MUST 在生产 mask 仍为几何真相的前提下，为可无损表达的单一加法图片映射
输出一个聚合轮廓的原生 `IMAGE` 图元，为可无损表达的单一文字映射输出一个完整原生
`STRING` 图元。`STRING.text` MUST 与 PCB Atelier 文字逐 Unicode 标量一致，不得把字符
拆成独立图元或依赖系统字体重新推断生产 mask。包含多个来源、减法布尔、无法表达的变换
或无法保证一致性的层 MUST 使用确定性聚合 `FILL` 回退或阻止导出，不得静默丢弃内容。
若目标 EasyEDA 版本接受 `STRING` 记录但不把它实例化到 2D/3D 场景，handoff MUST
同时输出与正式文字 mask 完全重合的同层兼容几何，保证制造与预览均不丢字。

#### Scenario: 导出单一图片映射
- **WHEN** 一个生产层仅包含一张经过正式处理的加法图片
- **THEN** EasyEDA 工程必须包含该层的一个 `IMAGE` 图元，其全部外环和孔洞聚合在同一路径中，manifest 仍能追溯正式生产 mask 和源实例

#### Scenario: 导出完整背面文字
- **WHEN** 背面丝印层包含文字 `Kamome`
- **THEN** EasyEDA 工程必须包含一个 `STRING` 图元且其 `text` 字段严格等于 `Kamome`，并包含同正式 mask 重合的兼容几何；六个字符均不得被裁切、遗漏、重排或拆分

#### Scenario: 复杂布尔层回退
- **WHEN** 一个生产层包含多个来源或 Add/Subtract 组合且不能由单一原生图片或文字无损表示
- **THEN** 适配器必须输出保持同一最终生产 mask 的聚合 `FILL` 或明确阻止导出，并在报告中记录回退原因

### Requirement: 底层原生图元只执行一次坐标转换
PCB Atelier MUST 继续以正向板坐标保存背面内容。EasyEDA 适配器 MUST 根据 EasyEDA Pro
底层原生图元的锚点语义，在导出边界对位置和查看方向执行且仅执行一次确定性转换；不得
同时预镜像路径并设置导致第二次镜像的图元属性。转换后图元 MUST 位于相同物理包围盒，
且在 EasyEDA 2D 底层编辑视图和 3D 物理背面视图中的可读方向必须与 EasyEDA Pro 原生
创建的非对称基准工程一致。

#### Scenario: 导出非对称背面图片
- **WHEN** 用户导出带偏心特征和非对称标记的背面图片
- **THEN** 图元必须落在预期底层和物理包围盒内，不能相对板框平移、重复镜像或使用与原生 `IMAGE` 相反的锚点

#### Scenario: 导出非对称背面文字
- **WHEN** 用户导出背面字符串 `Kamome`
- **THEN** EasyEDA 2D 顶面视图可按原生底层制造语义显示镜像，但切换到背面或在 3D 中翻至背面后必须可正向读取 `Kamome`，且不得缺少首尾字符或越过板框

## MODIFIED Requirements

### Requirement: 正式生产栅格必须导出为有界误差的矢量轮廓
EasyEDA 适配器 MUST 将正式生产 mask 的像素边界转换为确定性的平滑矢量路径，不得逐像素
保留可见的水平/垂直阶梯。轮廓相对正式生产边界的最大偏差 MUST 不超过一个正式生产像素
间距，并 MUST 保持外轮廓与孔洞的绕向、岛屿数量、孔洞归属、极性和物理包围盒语义。
输出轮廓 MUST 允许亚像素坐标、任意方向线段和 EasyEDA 支持的曲线路径。简化或平滑候选
若出现自交、退化、孔洞越界或拓扑变化，适配器 MUST 逐级降低平滑强度；仅在全部候选均
不安全时才对该环回退到精确边界，并 MUST 在导出报告中标记该回退。同一图片或同一回退
生产层的全部轮廓 MUST 聚合为一个可编辑图元，不得按字符或连通岛屿生成数百个独立对象。

#### Scenario: 放大查看斜线与曲线图片轮廓
- **WHEN** 用户把包含斜线、圆弧和孔洞的单色图片导出到 EasyEDA 并放大到足以检查边界
- **THEN** 导出图元必须使用连续平滑矢量边表达轮廓，不得呈现正式栅格的逐像素阶梯，且与正式生产 mask 的物理偏差不得超过一个正式生产像素间距

#### Scenario: 简化不能破坏小岛与孔洞
- **WHEN** 正式生产 mask 同时包含小岛、内孔和接近最小制造规则的细节
- **THEN** 矢量化后岛屿数量、孔洞归属和绕向必须保持不变；高强度候选不安全时必须使用安全的低强度候选或精确边界

#### Scenario: 一张复杂图片包含大量离散区域
- **WHEN** 一张处理后图片在同一生产层形成数百个互不连接的岛屿
- **THEN** EasyEDA 工程必须将这些轮廓保存在该图片的一个 `IMAGE` 或该层的一个聚合回退图元中，并保持各外环与孔洞可生产

#### Scenario: 轮廓质量自动验收
- **WHEN** 自动化测试比较同一复杂曲线的正式生产 mask 与导出路径
- **THEN** 测试必须同时验证最大几何偏差、岛屿和孔洞拓扑、无自交、路径聚合数量，并拒绝包含连续生产像素阶梯特征的结果
