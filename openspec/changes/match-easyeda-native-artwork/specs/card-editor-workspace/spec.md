## ADDED Requirements

### Requirement: 文字编辑代理与生产层语义一致
编辑模式 MUST 保持文字为可编辑的正向设计对象，并 MUST 使用该对象实际目标生产层的
物理外观绘制代理；不得因为对象位于背面、丝印、铜或阻焊开窗层而使用与生产预览无关的
固定文字颜色。对象内容、字符顺序、位置、缩放和方向 MUST 在编辑代理、编译生产 mask
和 3D 成板预览之间一致；视角造成的物理翻面仅可发生在 3D 查看阶段，不得回写文字内容
或持久变换。

#### Scenario: 编辑背面丝印文字
- **WHEN** 用户在背面丝印层创建 `Kamome` 并在正向背面画板编辑
- **THEN** 编辑画布必须完整显示六个字符、使用背面丝印的物理外观，并保持从左到右正立可编辑

#### Scenario: 从编辑切换到 3D 背面
- **WHEN** 用户保存背面文字后切换到 3D 并旋转到卡片背面
- **THEN** 3D 预览必须显示同一组六个字符和相同物理位置，并只按真实翻面视角表现方向

#### Scenario: 文字目标生产层改变
- **WHEN** 用户把文字从丝印层移动到同面的铜层或阻焊开窗层
- **THEN** 编辑代理必须更新为新目标层的物理外观，但文字内容、物理变换和稳定对象 ID 不得改变
