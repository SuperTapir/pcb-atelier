## ADDED Requirements

### Requirement: 大屏优先的可调整工作区 Dock
编辑器 MUST 以桌面大屏为主要工作环境，让生产层树与项目素材库默认并行可见，并允许用户
调整、折叠和持久化 Dock 尺寸。中央双画板和右侧检查器 MUST 保留可工作的最小尺寸；小屏
降级不得改变领域状态。

#### Scenario: 在 1920 宽度工作
- **WHEN** 用户以大屏打开编辑器
- **THEN** 图层树、素材库、双画板和检查器必须同时可用，用户可直接把素材拖到画板而无需切换左侧标签

#### Scenario: 恢复 Dock 布局
- **WHEN** 用户调整素材与图层面板比例、关闭并重新打开客户端
- **THEN** 系统必须恢复面板尺寸和折叠状态，同时保持工程内容与项目文件解耦

### Requirement: 三状态画板视图与全局设置本地持久化
系统 MUST 使用一个三状态选择器统一表达“左右”“上下”“聚焦当前面”，不得再把画板排列
和卡面查看拆成两组并列控件，也不得提供“自动”模式。无已保存偏好时 MUST 默认使用“左右”。
“聚焦当前面”只显示当前活动卡面，切换活动面时必须随之切换显示，但不得丢失另一面的选择、
视口或编辑状态。

顶部三状态选择器和设置页 MUST 读写同一个设备本地 `canvasView` 偏好，切换工程、关闭并
重新打开客户端后仍须恢复。设置页 MUST 以一个“默认画板视图”设置承载这三个值，并继续
承载主题、滚轮缩放阻尼、启动窗口方式及后续设备级全局偏好。启动窗口方式 MUST 提供
“窗口化全屏”“系统全屏”“普通窗口”三个稳定值并默认使用“窗口化全屏”；窗口化全屏
表示最大化普通窗口，保留系统窗口边界且不进入独占全屏空间。滚轮缩放阻尼 MUST 提供“高”“中”“低”
三档并默认使用“中”；高阻尼 MUST 比中阻尼缩放更慢，低阻尼 MUST 比中阻尼缩放更快。
画板视图、主题、启动窗口方式与缩放阻尼 MUST 与工程内容解耦，不得写入 `.pcba`、触发工程脏状态或进入
撤销/重做历史。

#### Scenario: 首次打开双画板
- **WHEN** 客户端没有已保存的 `canvasView` 偏好且用户打开任意双面工程
- **THEN** 正面和背面画板必须左右排列并同时可见，顶部选择器和设置页均必须显示“左右”

#### Scenario: 持久化上下排列
- **WHEN** 用户选择“上下”、关闭客户端并重新打开另一个工程
- **THEN** 双画板必须恢复为上下排列，偏好不得随工程切换而变化，也不得改写任一工程文件

#### Scenario: 持久化聚焦当前面
- **WHEN** 用户选择“聚焦当前面”、关闭客户端并重新打开工程
- **THEN** 系统必须只显示当前活动卡面并恢复“聚焦当前面”偏好，切换活动面后必须显示新活动面且保留另一面的视口和编辑状态

#### Scenario: 切换画板排列后自动适配
- **WHEN** 用户在“左右”“上下”或“聚焦当前面”之间切换
- **THEN** 系统必须在新布局稳定后按每块画板的实际可用区域重新适配缩放与居中位置，不得沿用旧布局下过小或被裁切的视口

#### Scenario: 在设置页修改主题
- **WHEN** 用户在设置页修改主题并重新启动客户端
- **THEN** 系统必须恢复该设备上的主题，且打开或保存工程不得序列化该主题偏好

#### Scenario: 持久化高阻尼
- **WHEN** 用户在设置页把滚轮缩放阻尼设为“高”、重启客户端并打开另一个工程
- **THEN** 设置页和画布必须继续使用高阻尼，且两个工程文件均不得记录该偏好或产生脏状态

#### Scenario: 默认以窗口化全屏启动
- **WHEN** 桌面客户端没有已保存的启动窗口偏好并首次打开
- **THEN** 主窗口必须以最大化普通窗口启动，默认逻辑尺寸不得小于 `1440 × 900`，且设置页必须显示“窗口化全屏”

#### Scenario: 持久化系统全屏
- **WHEN** 用户在设置页选择“系统全屏”并重新启动桌面客户端
- **THEN** 客户端必须进入系统全屏；改回“普通窗口”后下次启动不得继续最大化或进入系统全屏

### Requirement: 顶部模式控件保持稳定几何位置
画板三状态选择器 MUST 以整个应用窗口的几何中心为基准水平居中，不得因左侧 Dock、右侧
检查器宽度或其展开状态而偏移。编辑/预览切换 MUST 固定在顶部右侧的稳定位置并保持相同
占位尺寸，切换模式时不得导致自身、画板选择器或相邻控件跳动。撤销和重做 MUST NOT 常驻
顶部栏，但对应快捷键与菜单命令 MUST 保留并继续使用统一命令注册表。

#### Scenario: 左右面板宽度不同
- **WHEN** 用户调整左侧 Dock 或右侧检查器宽度
- **THEN** 三状态画板选择器的中心必须仍与应用窗口水平中心重合，不得仅相对剩余画布区域居中

#### Scenario: 切换编辑与预览
- **WHEN** 用户连续切换“编辑”和“预览”
- **THEN** 切换控件必须保持在顶部右侧同一几何位置且宽度稳定，三状态画板选择器不得位移

#### Scenario: 顶栏不显示撤销重做
- **WHEN** 用户进入编辑工作区
- **THEN** 顶部栏不得显示撤销或重做按钮，但 `Cmd/Ctrl+Z`、`Cmd/Ctrl+Shift+Z` 及菜单入口必须继续可用并反映相同历史状态

### Requirement: 左键内容与右键视口手势互斥
左键 MUST 只用于激活卡面、选择、框选和移动设计对象；右键拖动 MUST 平移开始手势的
画板且不改变选择。右键原地释放 MUST 打开指针所在对象或空白区域的上下文菜单。系统
MUST 使用移动阈值区分右键点击与拖动，并阻止浏览器原生菜单。

#### Scenario: 从图片上右键拖动画布
- **WHEN** 用户在已选图片内部按下右键并移动超过手势阈值
- **THEN** 只允许当前画板视口平移，图片选择和物理变换不得改变，也不得打开上下文菜单

#### Scenario: 右键点击图片
- **WHEN** 用户在图片上按下并原地释放右键
- **THEN** 系统必须选择或保持该图片并打开对象菜单，不得移动视口

#### Scenario: 左键拖动画板空白
- **WHEN** 选择工具下用户在空白处左键拖动
- **THEN** 系统必须显示框选区域并选择命中的未锁定对象，不得平移画布

### Requirement: 连续且指针锚定的滚轮缩放
滚轮或触控板缩放 MUST 使用输入事件的连续 delta 计算比例变化，不得把每次事件量化为固定
缩放台阶。缩放前后指针下的板上物理位置 MUST 保持不变。设备级“高/中/低”阻尼只能调整
delta 到缩放倍率的响应系数，不得改变缩放方向、锚点、最小/最大倍率或正背面独立视口语义。

#### Scenario: 不同 delta 产生不同缩放量
- **WHEN** 用户在同一阻尼档位、同一指针位置依次输入小幅和大幅同方向滚轮 delta
- **THEN** 两次缩放必须保持同一板上锚点，且大幅 delta 产生的倍率变化必须大于小幅 delta

#### Scenario: 高阻尼缩放更慢
- **WHEN** 用户分别在高、中、低阻尼下输入相同 delta
- **THEN** 三次缩放方向和指针锚点必须一致，倍率变化绝对值必须满足高阻尼小于中阻尼、中阻尼小于低阻尼

### Requirement: 画布 HUD 只保留方位与缩放
每块可见画板的 HUD MUST 只显示“正面”或“背面”以及当前缩放百分比。系统 MUST 移除板内
`FRONT`/`BACK` 大字、常驻手势教学提示、指针坐标读数、画板尺寸和当前生产层 badge。
对象坐标、物理尺寸、生产层和其他精确属性 MUST 由检查器按选择上下文提供，不得在画布上
重复常驻。

#### Scenario: 查看未选中的双画板
- **WHEN** 用户以左右或上下视图打开正背画板且没有选择对象
- **THEN** 每块画板只能看到对应“正面”或“背面”和缩放百分比，不得出现板内英文方位大字、手势提示、坐标、尺寸或生产层 badge

#### Scenario: 选择对象查看精确属性
- **WHEN** 用户选择一个已映射对象
- **THEN** 对象坐标、物理尺寸和生产层必须由检查器显示，画布 HUD 仍只能保留方位与缩放百分比

### Requirement: 统一编辑命令与快捷键作用域
系统 MUST 建立独立于 UI 入口的编辑命令注册表。快捷键、对象右键菜单、生产层菜单和
检查器 MUST 调用同一命令并获得相同的锁定校验、撤销记录和状态反馈。画布快捷键在文本
输入、数值输入、内容可编辑元素或模态窗口拥有焦点时 MUST 暂停。

#### Scenario: Delete 删除选择
- **WHEN** 画布拥有焦点且用户选中未锁定对象后按 `Delete` 或 `Backspace`
- **THEN** 系统必须删除源对象及其全部映射、保留项目素材并允许撤销

#### Scenario: P 插入图片
- **WHEN** 画布拥有焦点且用户按 `P`
- **THEN** 系统必须激活图片工具并聚焦项目素材库，后续插入目标跟随活动卡面和生产层

#### Scenario: 在文字输入中按快捷键
- **WHEN** 用户正在编辑文字并输入 `V`、`T`、`P` 或按 `Backspace`
- **THEN** 按键必须只作用于文字输入，不得切换工具或删除画布对象

### Requirement: 图层面板分组操作按选择上下文出现
图层面板 MUST NOT 在底部常驻大号分组或解组按钮。仅当多选内容可以组合，或当前选择包含
可解组的组合时，系统 MUST 显示紧凑上下文操作条，并只展示当前可执行的分组或解组动作。
没有可用动作时，操作条 MUST 完全隐藏且不得保留布局占位。操作条、右键菜单和快捷键 MUST
复用统一命令注册表及其启用条件、撤销和状态反馈。

#### Scenario: 多选可组合对象
- **WHEN** 用户在图层树或画布中选择两个可组合对象
- **THEN** 图层面板必须显示紧凑的“分组”操作，执行结果必须与右键菜单或快捷键分组一致

#### Scenario: 选中一个组合
- **WHEN** 用户只选中一个可解组的组合
- **THEN** 图层面板必须只显示紧凑的“解组”操作，不得同时显示不可执行的“分组”

#### Scenario: 没有分组上下文
- **WHEN** 用户没有选择、只选择普通单个对象或选择状态不允许分组与解组
- **THEN** 图层面板底部不得显示操作条或保留空白高度

### Requirement: 对象菜单与删除语义
对象上下文菜单 MUST 至少提供编辑、重命名、复制、创建副本、锁定、显隐、组合/解组、
关联到其他生产层、移出当前生产层和删除对象。删除对象 MUST 删除源对象和全部映射；
移出当前生产层 MUST 只删除当前映射，两者不得使用含糊的同一标签。

#### Scenario: 创建图片副本
- **WHEN** 用户通过 `Cmd/Ctrl+D` 或菜单创建图片副本
- **THEN** 系统必须创建新实例 ID、复用同一媒体资产、复制处理版本与生产映射，并以可见物理偏移放置副本

#### Scenario: 移出一个关联生产层
- **WHEN** Logo 同时关联铜和阻焊开窗且用户从阻焊开窗菜单选择“移出当前生产层”
- **THEN** 系统必须只移除阻焊开窗映射，Logo 实例和铜层映射必须保留

### Requirement: 编辑画布显示单一生产近似对象
图片、文字和图形在编辑画布中 MUST 以所属生产层的处理后轮廓和工艺近似色显示，而不是
默认显示会被生产处理改变的原始外观。生产近似 MUST 作为同一可编辑节点的外观，不得在
节点下方叠加完整编译纹理形成第二份内容。

#### Scenario: 图片确认导入后排版
- **WHEN** 用户把彩色图片处理为丝印黑白轮廓并确认插入
- **THEN** 画布必须显示该丝印轮廓和一个选择框，切换 3D 时不得出现原图到另一图案的结构突变

#### Scenario: 同一对象显示多个生产材料
- **WHEN** 一个对象关联多个当前可见生产层
- **THEN** 系统可以合成其材料近似，但只能保留一个命中目标、一个选择框和一套变换
