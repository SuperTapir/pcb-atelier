## ADDED Requirements

### Requirement: 素材、处理版本、实例与映射分离
工程 schema MUST 分别保存不可变原始素材、版本化图片处理配方、可放置图片实例和生产映射。
图片实例 MUST 保存稳定 ID、素材引用、裁切和物理变换；生产映射 MUST 保存目标面、目标层、
组合极性和所用处理版本。任何派生预览位图不得作为领域真相。

#### Scenario: 一个素材创建多个实例
- **WHEN** 用户从项目媒体库把同一 Logo 分别放到正面和背面
- **THEN** 工程必须只保存一份原始资产字节，并保存两个独立实例及各自合法生产映射

#### Scenario: 一个实例关联多个处理版本
- **WHEN** 一个图片实例同时关联正面铜和正面阻焊开窗
- **THEN** 两条映射可以引用不同处理版本，但必须共享同一实例变换、裁切和资产 ID

### Requirement: 当前 schema 严格加载与原子保存
系统 MUST 只接受本变更定义的当前工程 schema，并在形成可编辑工作区前完成反序列化、
引用完整性和制造配置校验。系统 MUST NOT 识别、推断或迁移旧图片、旧阈值、旧制造字段
或旧能力快照。加载或保存前校验失败 MUST 返回包含字段路径和原因的错误，且不得改写原工程
文件、生成半迁移副本或替换当前内存工作区。

#### Scenario: 打开非当前 schema 工程
- **WHEN** 用户打开 schema 标识、必填字段或枚举值不符合当前定义的 `.pcba` 工程
- **THEN** 系统必须拒绝加载并报告首批可定位错误，磁盘文件和当前已打开工程必须保持不变

#### Scenario: 保存前发现引用无效
- **WHEN** 当前工作区包含不存在的素材引用、处理版本引用或无效制造组合
- **THEN** 系统必须中止原子替换并保留上一次有效工程文件，不得写出部分有效的归档
