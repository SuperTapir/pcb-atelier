## ADDED Requirements

### Requirement: 制造配置与图片配方导出前一致性
EasyEDA 适配器 MUST 从已验证的制造配置和已解析生产板导出，不得重新解释原始图片或使用
UI 代理纹理。适配器 MUST 报告板厚、外层铜厚、阻焊、字符工艺、表面处理、处理配方指纹
及其支持状态；当前无法无损表达的制造工艺必须阻止“一键下单”声明。

#### Scenario: 导出标准丝印艺术卡
- **WHEN** 工程使用受支持的嘉立创 FR-4 配置、标准丝印和处理后图片
- **THEN** EasyEDA 工程的板尺寸、生产层图形、阻焊开窗、正背方向和制造摘要必须与编辑工艺近似及正式生产板一致

#### Scenario: 导出尚不支持的彩色丝印
- **WHEN** 工程启用嘉立创彩色丝印但当前适配器不能生成所需独立彩色生产资料
- **THEN** 系统必须阻止宣称可直接下单，说明缺失能力，并允许用户保留工程或改用标准丝印

### Requirement: 图片处理追溯信息
导出报告 MUST 记录每个图片生产图形的源实例、目标生产层、处理版本、算法版本和输入素材
哈希，使 EDA 中的图形可以追溯到 PCB Atelier 工程而无需嵌入原始隐私素材。

#### Scenario: 定位导出图片来源
- **WHEN** 用户检查 EasyEDA 导出报告中的一个丝印图形
- **THEN** 报告必须能定位对应图片实例和处理配方，并证明其几何来自正式生产 mask 而非编辑代理
