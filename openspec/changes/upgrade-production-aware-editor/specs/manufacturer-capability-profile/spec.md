## ADDED Requirements

### Requirement: 版本化制造能力配置
系统 MUST 将制造商、板材、层数、板厚、外层铜厚、阻焊油墨、字符工艺和露铜表面处理
保存为版本化制造配置，并按制造能力规则只提供合法组合。首个配置 MUST 面向嘉立创常规
FR-4 艺术板，但领域模型不得把供应商显示名称编码为生产几何。

#### Scenario: 选择不兼容工艺
- **WHEN** 用户选择的层数、板厚和表面处理组合不在当前嘉立创能力配置中
- **THEN** 系统必须在选择入口阻止或解释冲突，不得等到 EDA 导出后才失败

#### Scenario: 打开使用旧能力版本的工程
- **WHEN** 当前内置能力配置已更新，但工程保存的是旧版本配置
- **THEN** 系统必须保持旧工程可复现并提示可升级项，不得静默替换制造参数

### Requirement: 嘉立创阻焊与表面处理语义
首版嘉立创配置 MUST 区分 FR-4 基材、绿/红/黄/蓝/白/哑黑/嘉立创紫阻焊、标准黑白
字符，以及有铅喷锡、无铅喷锡、沉金和 OSP 表面处理。阻焊开窗 MUST 仅表示去掉油墨；
开窗与铜重合时才显示表面处理，没有铜时必须显示基材。

#### Scenario: 白色阻焊加沉金
- **WHEN** 用户选择白色阻焊和沉金
- **THEN** 编辑近似和 3D 必须以白色油墨表现盖油区、以金色近似表现露铜区，并以基材色表现无铜开窗

#### Scenario: 从沉金切换到无铅喷锡
- **WHEN** 用户只修改露铜表面处理
- **THEN** 铜和开窗几何不得变化，编辑近似及 3D 中的露铜材质必须从金色更新为银灰色

### Requirement: 标准丝印与彩色丝印分离
系统 MUST 把标准黑白字符与嘉立创彩色丝印作为不同生产工艺。彩色丝印的白色阻焊、
沉金、支持层数及下单限制 MUST 作为显式能力约束；在适配器尚不能输出所需彩色生产资料时
MUST 阻止宣称可直接下单。

#### Scenario: 普通白色阻焊选择黑色字符
- **WHEN** 工程使用标准丝印、白色阻焊和黑色字符
- **THEN** 系统必须按标准丝印生成单色 mask，不得误标为彩色丝印订单

#### Scenario: 不满足彩色丝印条件
- **WHEN** 用户在非白色阻焊或非沉金配置下启用嘉立创彩色丝印
- **THEN** 系统必须指出不满足的制造条件并保持当前可生产配置不变

### Requirement: 编辑态工艺近似即时更新
系统 MUST 在编辑模式快速显示阻焊、字符、基材和露铜表面处理的工艺近似色，并明确说明
屏幕颜色不是批次级实物色彩保证。仅修改调色板参数不得重建生产几何 mask。

#### Scenario: 编辑态切换阻焊颜色
- **WHEN** 用户在板体检查器把阻焊从绿色改为嘉立创紫
- **THEN** 正背画板必须立即同步更新底色，同时保持对象位置、处理轮廓、选择和视口不变
