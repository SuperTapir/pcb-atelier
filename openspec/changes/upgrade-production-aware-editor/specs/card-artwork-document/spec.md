## ADDED Requirements

### Requirement: 素材、处理版本、实例与映射分离
工程 schema MUST 分别保存不可变原始素材、版本化图片处理配方、可放置图片实例和生产映射。
图片实例 MUST 保存稳定 ID、素材引用、裁切和物理变换；生产映射 MUST 保存目标面、目标层、
组合极性和所用处理版本。任何派生预览位图不得作为领域真相。

#### Scenario: 一个素材创建多个实例
- **WHEN** 用户从项目媒体库把同一 Logo 分别放到正面和背面
- **THEN** 工程必须只保存一份原始资产字节，并保存两个独立实例及各自合法生产映射

#### Scenario: 一个实例关联多个处理版本
- **WHEN** 一个图片实例同时关联正面铜和正面阻焊开窗
- **THEN** 两条映射可以引用不同处理版本，但必须共享同一实例变换、裁切和资产 ID

### Requirement: 媒体与制造配置 schema 迁移
工程 schema 升级 MUST 为现有嵌入资产、图片层、叠层参数和生产映射提供确定性迁移，并
在保存前完成完整校验。迁移失败 MUST 保留原工程不变并报告具体字段。

#### Scenario: 迁移现有图片工程
- **WHEN** 打开上一 schema 的有效图片工程
- **THEN** 每个旧图片层必须迁移为素材引用、兼容处理版本和图片实例，迁移前后的生产输出哈希必须保持兼容

#### Scenario: 迁移旧表面处理
- **WHEN** 工程只保存旧 `enig` 或 `haslLeadFree` 叠层字段
- **THEN** 系统必须映射到版本化制造配置中的沉金或无铅喷锡选项，不得改变板尺寸和生产图形
