# PCB Atelier：未来产品规划

## 1. 背景

当前 PCB_lightgraph Neo 已经验证了一些有价值的能力：

- 以梅琳娜作品为实际样本完成的阻焊雕刻金属工艺；
- 双面艺术卡片；
- 板框、孔位、PTH 焊环和基础制造输出；
- 图片到铜、阻焊和丝印生产层的基本转换；
- EasyEDA 与 Gerber 导出的初步闭环。

但当前产品也暴露出明显问题：

- 大量实验工艺没有经过“源图—Neo—EDA—Gerber—实板”的完整验证；
- Neo 内部预览与导入 EDA 后的结果可能发生明显变化；
- 普通用户面对大量阈值、通道和工艺参数，仍然不知道如何得到目标成品；
- 高级用户无法方便地同时查看、叠加和编辑多个内容层与生产层；
- 当前 UI 把配方、通道、蒙版、板框和制造参数平铺在同一个层级，缺少清晰的制作流程；
- “一张图片选择一个复杂配方”的模型，不符合创作者实际使用多份图片、蒙版、线稿和装饰资产的工作方式。

老师们真正重复的工作通常是：

```text
处理原图
→ AI / PS / 抠图 / 黑白 / 反相 / 线稿化
→ 导出多份处理结果
→ 导入 EDA
→ 指定铜、阻焊、丝印和正反面
→ 统一尺寸、坐标和方向
→ 查看叠加结果
→ 返回修改图片
→ 再次导入和对齐
```

新产品的目标，是承担图片处理与 EDA 之间的制作工作，消除这段跨工具、反复导入和
反复对齐的低效流程。它不试图替代所有图片软件，而是把高频、简单、可预测且直接
影响 PCB 制造结果的处理，与图层编排、工艺映射和预览放进同一个项目。

## 2. 产品定义

新产品不是完整电子 EDA，也不是完整 Photoshop。

它是一个：

> 面向 PCB 艺术板的图像处理、图层编排、生产层设计、真实预览和制造交接工作台。

可以把它理解为：

> Sketch 的图层与对象体验
> ＋ PCB EDA 的生产层语义
> ＋ 少量针对 PCB 图片的非破坏处理
> ＋ 可复现的 CLI 与制造输出

完整 EDA 仍然负责复杂原理图、网络、封装、布线和电气设计。对于纯艺术板或只包含简单孔、焊盘和装饰电路的项目，用户应当可以主要在新产品中完成作品，只在最后进入 EDA 检查、补充电路或下单。

产品的核心价值是把创作者的视觉意图——例如人物轮廓做沉金、白色细节做丝印、背景
保留为阻焊——转换为可制造的 PCB 生产层。创作者应先围绕视觉内容工作，再由产品
把它可靠地映射为 EDA 和板厂理解的工艺表达。

## 3. 核心目标

### 3.1 普通用户

普通用户不需要先理解完整 EDA，只需要：

1. 创建板子；
2. 导入图片；
3. 调整构图；
4. 选择期望的材料表现；
5. 做少量必要修正；
6. 查看可信的实体板预览；
7. 生成可以直接检查、下单或继续编辑的文件。

默认流程中不应暴露大量算法参数。参数应该围绕用户目标表达，例如：

- 保留更多细节；
- 减少细碎线条；
- 加粗金属轮廓；
- 简化背景；
- 保护人物五官；
- 降低丝印与金属套准风险。

### 3.2 高级用户

高级用户需要的是对资产、内容图层和生产层的直接控制：

- 同时查看多个内容层和生产层；
- 控制图层显隐、锁定、顺序和预览透明度；
- 自由映射内容到顶铜、阻焊、丝印及背面层；
- 为生产层增加或挖空局部区域；
- 编辑蒙版、移动区域和替换外部资产；
- 精确调整毫米尺寸、坐标、旋转和镜像；
- 调用 CLI 批量处理和比较不同参数；
- 在需要时继续进入 PS、Sketch 或 EDA。

## 4. 产品原则

### 4.1 生产层是真相来源

预览不能是与导出无关的效果图。

实体板预览、生产层 PNG、首版选定的 EasyEDA 交接产物和 Gerber 必须由同一份生产层
数据生成，并共享：

- 物理尺寸；
- 原点；
- 正反面方向；
- 图层极性；
- 板框裁切；
- 铜、阻焊开窗和丝印的组合关系；
- 孔位与安全间距。

对于首版选定的 EDA 交接产物，导入或重开后的生产几何若与产品预览不同，应视为
产品缺陷，而不是正常误差。首版交接产物是否为可继续编辑的 EasyEDA 工程，仍需由
黄金样本验证后决定。

这里的“一致”分为两个层次：

- **制造几何必须一致**：2D 预览、3D 预览、首版选定的 EasyEDA 交接产物与 Gerber
  的位置、尺寸、旋转、镜像、板框、孔位和层极性必须来自同一份生产层数据；
- **材料表现允许近似**：沉金色泽、铜反光、阻焊半透明和丝印质感应帮助用户判断
  成板效果，但不承诺完全复刻每家板厂、每种工艺的摄影级外观。

### 4.2 项目必须可复现

任何作品都应能够通过项目文件和 CLI 在另一台机器上重新生成。

工程不应依赖用户记忆某个外部文件夹中的“最终版 3.png”。项目必须记录资产、处理关系、尺寸、层映射、人工修正和导出版本。

### 4.3 GUI、CLI 与 Agent 使用同一核心

GUI 不直接实现独立算法，CLI 也不能拥有另一套导出逻辑。

所有操作都应进入统一核心：

```text
项目文件 / GUI 操作 / CLI 命令 / Agent 工具调用
                       ↓
                    Core
                       ↓
      资产处理 → 生产层编译 → 检查 → 预览与导出
```

## 5. 项目与资产模型

一个项目应绑定完整创作资产，而不只保存正反面各一张图片。

典型资产包括：

- 原始插画；
- 抠图结果；
- AI 或 PS 处理稿；
- 黑白线稿；
- 反相图；
- 人物或局部蒙版；
- Logo、文字和装饰；
- 板框参考；
- EDA 工程；
- Gerber 快照；
- 实板照片；
- 作者、来源和授权记录。

资产之间应保存派生关系：

```text
原始插画
├── 人物抠图
├── 金属线稿
│   ├── 顶铜
│   └── 顶阻焊开窗
├── 白色细节
│   └── 顶丝印
└── 背景装饰
    └── 底丝印
```

### 5.1 嵌入与链接

项目支持两种资产模式：

- **嵌入项目**：复制资产并随工程保存，保证工程可移动和可复现；
- **链接外部文件**：适合继续使用 PS、Sketch 等工具编辑，文件变化后提示刷新。

外部文件更新后，内容层保持原有物理尺寸、坐标、旋转、生产层映射和人工修正。

导出时必须创建确定的资产快照，防止外部文件后续变化导致历史制造结果无法复现。

## 6. 双层图层系统

### 6.1 内容图层

内容图层是创作者能够直接理解和编辑的对象，例如：

- 人物；
- 头发线稿；
- 五官细节；
- 服装色块；
- Logo；
- 文字；
- 边框；
- 背景纹理；
- 蒙版和挖空对象。

内容图层支持：

- 添加、复制、删除和重命名；
- 分组；
- 拖动排序；
- 显隐与锁定；
- 预览透明度；
- 位置、尺寸、旋转和镜像；
- 对齐和分布；
- 链接或嵌入资产；
- 非破坏图像处理；
- 基础蒙版与增加/挖空。

### 6.2 生产层

首版生产层至少包括：

- Top Copper；
- Top Solder Mask Open；
- Top Silkscreen；
- Bottom Copper；
- Bottom Solder Mask Open；
- Bottom Silkscreen；
- Board Outline；
- PTH / NPTH Drill。

一个内容图层可以映射到多个生产层。例如沉金图案同时写入顶铜与顶阻焊开窗。

一个生产层也可以包含多个内容图层：

```text
Top Copper
├── 人物沉金轮廓
├── 金属边框
├── Logo
└── 首饰高光
```

内容图层映射到生产层时至少支持：

- 添加；
- 挖空；
- 裁切到板框；
- 避让孔位；
- 正反面镜像规则；
- 制造最小线宽与间隙修复。

## 7. 图像编辑范围

新产品需要比普通 EDA 更强的图片能力，但首版不追求替代 PS。

### 7.1 首版必须具备

- 裁切和画布适应；
- 移动、缩放、旋转和镜像；
- 灰度、黑白和反相；
- 阈值与基础色阶；
- 亮度、对比度和轻度锐化；
- 简单背景去除或透明度导入；
- 线条加粗与收缩；
- 小区域清理；
- 简单颜色范围选择；
- 矩形、椭圆、套索或钢笔蒙版；
- 添加与挖空；
- 板框、孔位和安全距离裁切。

### 7.2 首版不做

- 专业绘画系统；
- 修复画笔和液化；
- 大量 PS 混合模式；
- 完整路径布尔建模工具；
- 复杂智能对象与高级滤镜；
- 无法映射到 PCB 生产结果的视觉特效。

复杂抠图、精修和绘画继续交给 PS、Sketch 或其他专业工具完成。

## 8. 真实预览

预览至少需要三种模式：

### 8.1 内容编辑预览

显示原图、内容图层、蒙版和处理结果，适合构图与编辑。

### 8.2 2D 生产层预览

允许同时显示多个生产层，并支持：

- 显隐；
- 独立颜色；
- 透明度；
- 单层隔离；
- 正反面切换；
- 极性检查；
- 清理前后差异。

这是制造前最精确的检查视图。用户应能在此发现正反面镜像、阻焊开窗极性、图案位置、
板框裁切、孔位冲突、丝印覆盖金属和细节过细等问题。

### 8.3 3D 实体材料预览

严格基于生产层组合模拟：

- 铜；
- 阻焊覆盖；
- 阻焊开窗；
- 沉金或喷锡；
- 标准丝印；
- 可选专色或彩印；
- 基材和板框。

实体预览使用的几何与导出使用的几何必须相同。它的目标是让用户在进入 EDA 前判断
作品大概会是什么样子，而不是替代板厂打样或承诺精确材质颜色。

## 9. 板子与基础 EDA 能力

产品不需要首版实现完整电路设计，但应覆盖艺术板常用结构：

- 物理尺寸画布；
- 矩形、圆角矩形和可编辑板框；
- PTH 与 NPTH；
- 焊盘和焊环；
- 简单槽孔；
- 铜到板边距离；
- 丝印到露铜距离；
- 正反面结构；
- 简单对齐标记；
- 可选的少量装饰走线或基础功能模块。

简单艺术板应能直接导出制造文件，或只在 EDA 中做最后确认；需要复杂电路、器件、
网络、布线或高级 DRC 时，用户可以导出到 EDA 继续设计。EDA 是重要的最终出口，
但不应迫使用户重新完成图片拆分、图层组合和版面定位。

## 10. CLI

CLI 是核心能力，不是后期附加功能。

示例：

```bash
neo project create work.pcba --board 64x100mm
neo asset add source.png --name character
neo layer derive character --effect grayscale
neo layer derive character --effect line-art --line-width 0.22mm
neo map line-art --to front.copper,front.mask-open
neo render work.pcba --mode material --output preview.png
neo check work.pcba
neo export work.pcba --format easyeda
neo export work.pcba --format gerber
```

CLI 应支持批量参数比较：

```bash
neo sweep work.pcba \
  --set line.threshold=60,80,100 \
  --set line.width=0.18mm,0.22mm,0.25mm \
  --contact-sheet comparisons.png
```

CLI 的主要用途：

- 批量制作同系列作品；
- 自动生成多种尺寸或工艺版本；
- 比较参数组合；
- CI 中检查输出稳定性；
- 无界面服务器运行；
- 未来供 Agent 调用。

## 11. 未来 Agent

未来可以在右侧提供 Agent 面板，接入：

- 用户自己的 OpenAI 或 Anthropic API Key；
- 其他兼容 API 供应商；
- 本地 Claude Code；
- 本地 Codex；
- 其他遵循工具协议的 Agent。

Agent 不直接模拟点击界面，而是通过稳定的 Core API 或 CLI 操作项目。

用户可以提出：

- “减少头发的沉金细线，但保护眼睛。”
- “把首饰移到沉金，荷叶边放到白色丝印。”
- “生成三种线宽让我比较。”
- “删除右下角椅子在所有生产层中的内容。”
- “检查为什么 EDA 中的阻焊结果反了。”

Agent 应先生成可审查的变更集：

```text
计划修改：
- 金属线稿阈值：70 → 92
- 制造线宽：0.22 → 0.20 mm
- 增加眼睛保护蒙版
- 从铜、阻焊开窗和丝印中删除右下角区域
```

用户能够查看前后差异，然后选择应用或放弃。

安全要求：

- API Key 保存到系统钥匙串，不进入项目文件或日志；
- 上传图片或工程到云端模型前明确告知用户；
- Agent 修改可撤销并保留审计记录；
- Agent 不能绕过制造检查；
- 本地与云端 Agent 使用同一工具协议；
- 项目工具限制 Agent 的文件访问和修改范围。

Agent 属于后续规划。首版只需要保证项目模型、命令系统和差异机制能够支持未来接入。

## 12. 与当前项目的关系

这可以是一个全新的项目，而不是在当前 UI 和工程模型上继续重构。

### 12.1 可以复用

- Rust 图像解码与基础处理算法；
- 铜、阻焊、丝印的材料组合经验；
- Gerber / Excellon 导出代码与测试；
- EasyEDA 导出与坐标、极性、镜像经验；
- 梅琳娜阻焊雕刻金属黄金样本；
- 双面卡片、板框、孔位和焊环能力；
- 现有制造规则与错误案例；
- `.reference` 中的公开视频证据和工艺分类；
- 已有 E2E、黄金测试和生产包结构验证方法。

所有复用代码都应通过新项目的接口重新接入，而不是直接复制当前页面结构。

### 12.2 不应直接继承

- 当前以“一面一张图＋一个大配方”为核心的工程模型；
- 当前所有设置平铺在右侧面板的 UI；
- 未经真实闭环验证的大量实验工艺；
- 与真实导出数据不一致的预览捷径；
- 只能单层切换、无法多层叠加的查看方式；
- 把算法参数直接暴露给普通用户的交互；
- 为了保留旧 schema 而增加的兼容负担。

### 12.3 当前项目的定位

当前 PCB_lightgraph Neo 作为：

- 原型；
- 算法与导出实验场；
- 已验证工艺的参考实现；
- 新产品的错误案例和测试资料库。

新项目可以从新的项目模型和 UI 架构开始，不要求兼容当前 schema。

## 13. 验证方法

每个对外能力必须通过可重复闭环证明有用。

### 13.1 黄金作品

首个黄金样本使用已经有真实经验的梅琳娜阻焊雕刻金属作品：

```text
源图
→ 内容层
→ 生产层
→ 实体预览
→ EasyEDA
→ Gerber
→ 实板或已验证制造结果
```

第二个黄金样本使用双面卡片，验证：

- 正反面方向；
- 独立图案；
- 孔位与焊环；
- 板框；
- EDA 和 Gerber 一致性。

在这两条路径稳定之前，不新增更多复杂工艺。

### 13.2 一致性检查

至少建立：

- Core 生产层黄金测试；
- GUI 与 CLI 相同项目输出哈希或几何一致性测试；
- PCB Atelier 生产几何与首版选定的 EasyEDA 交接产物之间的几何、图层语义
  一致性测试；
- 3D 材质预览的视觉回归测试与明确容差；
- Gerber 层极性、尺寸和坐标测试；
- 正反面镜像测试；
- 最小线宽、间隙、板边和孔位检查；
- 项目保存、移动、重开和外部资产更新测试。

## 14. 分阶段计划

### 阶段 0：保留当前项目

- 当前仓库转为 Private；
- 保留现有代码、文档、参考资料和测试；
- 不继续在旧 UI 中增加实验工艺；
- 把已验证能力和失败案例作为新项目输入。

### 阶段 1：新核心与项目格式

- 定义资产、内容图层、生产层和派生关系；
- 定义可版本化的项目格式；
- 建立统一命令模型；
- 提供最小 CLI；
- 使用梅琳娜样本验证生产层编译。

### 阶段 2：画布与图层工作区

- 毫米画布；
- 内容图层面板；
- 多层显隐、锁定、排序和分组；
- 移动、缩放、旋转、镜像和对齐；
- 基础图像处理；
- 基础蒙版与增加/挖空。

### 阶段 3：生产层与真实预览

- 内容层映射到生产层；
- 多生产层叠加；
- 实体材料预览；
- 板框、孔和焊环；
- 预览与导出共享几何。

### 阶段 4：EDA 与制造闭环

- EasyEDA 工程导出和重开校验；
- Gerber / Excellon；
- 本地制造检查；
- 双面卡片黄金样本；
- 保存可复现导出快照。

### 阶段 5：普通用户流程

- 把黄金工程整理为少量可靠的引导工作流；
- 用目标语言代替算法语言；
- 提供修改前后对比；
- 减少普通流程中的必要决策。

### 阶段 6：Agent

- 稳定工具协议；
- 右侧 Agent 面板；
- 本地 Claude Code / Codex；
- 用户自带 API Key；
- 变更计划、差异预览、确认和撤销。

## 15. 暂不解决的问题

新项目首版暂不承诺：

- 替代完整原理图与 PCB 布线 EDA；
- 自动理解眼睛、头发、人物和背景等所有语义；
- 一键复刻任何老师作品；
- 未经打样即可保证彩色丝印色差；
- 自动完成复杂 PS 精修；
- 直接接管板厂在线下单账户；
- 在没有真实生产验证的情况下提供大量复杂工艺。

## 16. 首版完成标准

首版不是以功能数量判断完成，而是满足以下结果：

1. 用户能够在一个项目中管理原图、派生图和外部编辑资产；
2. 用户能够像使用简化版 Sketch 一样管理多个内容图层；
3. 内容可以明确映射到铜、阻焊、丝印和正反面；
4. 用户能够同时查看多个生产层；
5. 实体预览与最终导出使用同一份生产数据；
6. 梅琳娜和双面卡片两个黄金样本能够稳定重现；
7. CLI 可以无界面重新生成预览、EDA 和 Gerber；
8. 普通用户不需要理解大量算法参数；
9. 高级用户不需要回到 EDA 才能完成基本图片叠加与位置调整；
10. EDA 主要承担最后检查、复杂电路补充和下单，而不是重复图片编辑工作。

达到这些标准后，再讨论更多二次元工艺、彩色丝印、半调、复杂板框和 Agent 自动制作。
